Data: 2026-08-12

## Regra aprovada
Quando a pergunta for "Hoje você já possui uma conta PJ? Se sim, qual banco você utiliza?":

- Cliente responde "não" → seguir para faturamento.
- Cliente responde que possui Santander sem indicar PF → interpretar como conta PJ e direcionar/bloquear.
- Se o cliente informar explicitamente que a conta Santander é PF → não bloquear e continuar o atendimento.
- Não perguntar novamente PF/PJ quando a pergunta original já foi sobre conta PJ.

Esta versão preserva os fluxos anteriores já aprovados.
